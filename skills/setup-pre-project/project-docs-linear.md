# Project docs: Linear

How the pre-project skills find a project and write its phase documents.

- **Project**: a Linear project, named by its identifier (`P-XXX-123`), URL or name. Its description, comments, linked issues and feedback are the need.
- **Phase documents**: Linear documents attached to the project, created and updated with the Linear tools (`save_document` with `project`; `patch` to edit part of one).
- **Titles**: « {{preliminary study title}} », « {{exploration title}} », « {{architecture title}} ».
- **Language**: {{language}}.
- **Diagrams**: Mermaid code blocks. Linear's rendering of them is not guaranteed: say so in the document when a diagram carries a decision, and offer an HTML page alongside.
- **Agent notes**: a collapsible section, opened by `+++ Agent notes` on its own line and closed by `+++` on its own line.
- **Vocabulary source**: {{the glossary from domain.md, or another file}}.
